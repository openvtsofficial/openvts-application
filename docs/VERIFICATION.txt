SESSION POLICY AND RELEASE LIMITS
The supplied backend defaults to access tokens of 24 hours and refresh tokens
of seven days, renewed on successful refresh. Normal use/outages do not trigger
premature logout; inactivity or offline time beyond refresh expiry needs login.
Password/MFA changes, revocation, account deactivation and role changes are honored.
Changing the server expiry policy requires a backend configuration change.

Android/iOS SDKs, signing identities, physical devices and live credentials were
unavailable. No signed native build is supplied. Validate staging with six real
roles, actual fleet membership, live stop/start, time displays, permissions,
retention, MFA, refresh/rotation, reports and native integrations before release.
Native Driver FCM remains withheld because the supplied push-token schema uses
User identities while Driver identities are separate; backend support is required.
Route-provider availability still affects road routing; a failed request preserves
the draft and does not save a fabricated straight-line route.
